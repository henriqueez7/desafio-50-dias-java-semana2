# Gerenciador de Tarefas em Java

Projeto desenvolvido durante a **Semana 2 do Desafio de 50 Dias de Código**, com o objetivo de praticar lógica de programação, estruturas de dados e Programação Orientada a Objetos (POO) utilizando Java.

---

## 🎯 Objetivo do Projeto

Criar um sistema simples de gerenciamento de tarefas em memória (mini CRUD), executado via terminal, permitindo ao usuário:

* Criar tarefas
* Listar tarefas cadastradas
* Buscar tarefas pelo ID
* Atualizar título e status de uma tarefa
* Remover tarefas

Os dados são armazenados apenas enquanto o programa está em execução (sem banco de dados ou arquivos).

---

## 🧠 Conceitos Praticados

* Programação Orientada a Objetos (POO)
* Listas (`ArrayList`)
* Estruturas de repetição (`for`, `do-while`)
* Estruturas condicionais (`if`, `switch`)
* Encapsulamento (getters e setters)
* Regras de negócio e validações
* CRUD em memória

## ▶️ Como Executar

1. Clone o repositório
2. Abra o projeto em uma IDE Java (IntelliJ, Eclipse, VS Code)
3. Execute a classe `Main.java`
4. Interaja com o menu pelo terminal

---

## 📋 Funcionalidades

* Cada tarefa possui:

    * ID único
    * Título
    * Status (`PENDENTE` ou `CONCLUIDA`)

* O sistema valida:

    * ID inexistente
    * Status inválido
